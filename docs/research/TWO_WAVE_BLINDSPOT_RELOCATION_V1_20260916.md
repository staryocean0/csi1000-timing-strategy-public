# Two-Wave blindspot relocation V1 — preregistration

This study is the bridge between the passed scale-specific continuity representation and the downstream 5m recognizer-readiness gate #321.

It does **not** repair the recognizer. It reuses the exact frozen blind episodes from cycle-identifiability V1 and asks where they physically sit once the higher C2/C3 representation is allowed to remain continuous across lower-level root boundaries.

Two maps remain separate. The retrospective map may use fully completed continuous C2/C3 occurrence geometry to answer where the blind episode physically occurred. The causal map uses only state known at each historical bar and may later inform a detector rule. Retrospective labels are never backfilled as live state.

The primary evidence is concentration relative to exposure, not raw episode counts. A state that contains many blind bars only because it occupies most of the sample is not a useful explanation.

No PnL, returns, router outcome, 1m data, target-period tuning or detector parameter change is allowed in this run. Any subsequent repair candidate must be registered before seeing its own real aggregate result.
