# 本频段周期可识别性 × C2 位置诊断 V1

本研究回答的不是“如何强行把每段行情都分成波”，而是：**当前冻结的本频段波算法，什么时候自然看不出周期；这些盲区是否集中在二级低频 C2 的某些位置。**

## 用户对 1 分钟数据的关键澄清

1 分钟数据未来可以有两种完全不同的用途。若只是把现有 5 分钟物理周期细采样，它不会增加高层独立周期；但如果把新的本频段重新定义为例如 `10×1m`，它就会真正新增一个更快的物理层级。因此“同跨度1m不是 C3 样本救援”与“1m可作为新的更快 base scale”并不矛盾。当前 V1 先不用 1m，因为先要解释冻结 5m base 为什么失明。

## 两张图必须分开

- **Retrospective morphology map**：允许事后完整 C2 波定位，只回答盲区实际上发生在 C2 的上涨/回落、早/中/晚哪个位置。不能当实时信号。
- **Causal as-of map**：每根 bar 只使用当时已经确认的 C2 状态，统计距离最近本级波确认多久、最近一个/两个 T0 内有多少波确认。只有这一张以后可能演化成状态信号。

## “看不出周期”不先硬切一个阈值

首先保存连续量：完整 base 波对 occurrence bar 的覆盖率、未覆盖 episode 长度、raw high-low log range、路径总变差、路径效率、距离上次 wave confirmation 的 T0 倍数，以及 T0/2T0 内的确认密度。盲区再按左截断、右截断、reset/root break、未完成结构分类。

尤其要比较盲区 raw range 相对已完成 base 波振幅的四分位：如果 Q3/Q4 仍大量看不出波，就不是简单“振幅太小”，而是识别数学有结构性缺口。

## C2 位置

回顾图按完成 C2 波的整体迁移 `UP/RANGE/DOWN`、当时位于 low→high 还是 high→low 腿、以及 early/middle/late 三段统计。因果图按当时已确认的 C2 descriptor、当前 leg direction、causal phase 和振幅四分位统计。

研究结果允许四种结论：小振幅噪声为主；大振幅盲区集中于特定 C2 相位；盲区主要由 root fragmentation 决定；或没有稳定集中规律。**不允许因为想得到“底部横盘”结论而事后改定义。**

本轮不看收益、不做路由、不修 detector。若结果指向 root fragmentation，再回到 #315；若指向稳定 C2 phase，则把它同时作为候选状态信号和下一版 detector 的验收场景。
