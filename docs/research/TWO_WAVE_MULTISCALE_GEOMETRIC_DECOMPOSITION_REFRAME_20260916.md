# Two-Wave 多尺度图形分解：金融命题与数学承载重新对齐（2026-09-16）

## 1. 研究对象不是“证明金融直觉”，而是验证数学对象是否忠实承载金融直觉

本轮纠偏不否定用户提出的金融逻辑。A/B 两项此前真实 pilot 的不足首先解释为“数学表示与信息覆盖是否充分”的问题，而不是把金融原理判为错误。

核心金融命题：本级别交易行为同时受相邻更低频结构和更慢低频结构影响。相邻低频若主导并接近自身转折，相对容易反复扭转本级别趋势；更慢一级低频若主导且方向一致，本级别趋势在其内部更可能具有持续性。反向问题是，小级别九格及单波内部形状是否对上一层低频结构的相位变化/转折提供增量信息。

## 2. 正确的数学承载：图形多分辨率分解，而不是传统线性滤波

设原始对数价格为 `X0(t)`。使用已经冻结的因果单波识别器，从 `X0` 上得到本级别完整波，并用这些波的低点连接形成第一条低点骨架 `S0(t)`。

- `C0(t) = X0(t) - S0(t)`：本级别波内部成分。
- 在 `S0` 上再次使用同一种图形波识别思想，得到更粗一层低点骨架 `S1(t)`。
- `C1(t) = S0(t) - S1(t)`：一级低频，也就是紧邻本级别下面的低频成分。
- 再在 `S1` 上识别波并连接低点得到 `S2(t)`。
- `C2(t) = S1(t) - S2(t)`：二级低频。
- 后续可继续递归，但首轮只要求 C1/C2。

这是非线性的、基于确认波的图形多分辨率分解。它与“逐层平滑再做相邻层差分”的思想相似，但不使用卷积、傅里叶、拉普拉斯等传统滤波核，也不把层号直接等价于某个固定周期。

## 3. 周期必须从各层真实识别出的波来量，不允许先规定“2–3倍”再找答案

本级别周期 `T0` 来自本级别已确认波的实际 duration；一级低频周期 `T1` 来自 S0 上识别出的一级低频波；二级低频周期 `T2` 来自 S1 上识别出的二级低频波。

因此：

- `T1/T0` 是否集中在 2–3，本身是待检验事实，不是构造条件。
- `T2/T0` 是否明显更大，同样由数据给出。
- 如果相邻层并不天然落在 2–3 倍，不能为了匹配原假设强行把它改成 2–3 倍。
- 目标是识别“下一层、下两层”的实际尺度，再观察这些尺度与本级别交易稳定性的关系。

## 4. 每一层至少保存四个量：周期、振幅、方向、相位

仅用窗口方差/残差能量不足以承载金融命题。每个层级 k 应直接从该层的波保存：

- `Tk`：该层实际波长/周期。
- `Ak`：该层实际波振幅，可同时保留 log peak-to-trough、channel height 等原始量。
- `Dk`：当前可知方向/底线迁移方向。
- `Phik`：当前在该层波中的因果位置或相位状态；未确认完整父波时不能使用未来终点反推相位。

附加保存 `Ak/Tk` 作为单位时间推进强度，以及相对本级别的 `Ak/A0`、`(Ak/Tk)/(A0/T0)`。这些是描述量，不预设最优阈值。

“哪个低频起作用”不能只由整窗 variance 最大决定，而应至少同时观察：实际层级波振幅、周期比例、方向是否与本级别交易一致、以及是否处在接近转折的相位。

## 5. B 的正确验证对象：一级低频主导 vs 二级低频主导

B 不应先问某个过滤器是否赚钱，而应先验证图形分解本身：

1. 在每一个本级别交易决策时点，C1/C2 是否因果可得？覆盖率分别是多少？
2. `T1/T0`、`T2/T0` 的真实分布是什么？
3. 一级低频强、二级低频弱时，本级别趋势跟踪的反复翻转/快亏是否更高？尤其在 C1 与本级别方向冲突或 C1 接近自身转折时。
4. 一级低频弱、二级低频强且方向一致时，本级别趋势持续率是否更高、快亏是否更低？
5. 二级低频强但处在其自身转折附近时，不能自动归入“安全趋势阶段”。相位必须参与解释。

先检验结构与 whipsaw/continuation 的关联，再讨论经济收益。不能用 coverage=0 的过滤结果否定金融命题。

## 6. A 的正确验证对象：小级别结构是否提示上一层低频相位变化

A 与 B 应使用同一套层级分解，而不是两个彼此无关的数学系统。

- 父对象直接定义为一级低频 C1/S1 的图形波，而不是额外发明另一套大周期标签。
- 在本级别一个严格 pair 完成确认时，只使用当时已经确认的一级低频信息。
- 基准模型只用一级低频自身的方向、振幅、已运行时间/相位证据。
- 增量一加入本级别九格、两波斜率/振幅关系。
- 增量二加入当前小波内部形状，例如峰值早晚、前后推进、效率和相对振幅。
- 目标是之后新发生的一级低频拐点/相位变化，不把早已发生但晚确认的父拐点算作提前预测。

这回答的是：小波是否是大波相位变化的微观先行信息，而不是用小波直接预测任意未来涨跌。

## 7. 对 35065802258-1 的重新解释

现有 B 实现并非使用 FFT。它确实把本级别波低点形成 root，再递归对低点节点提取父级波；因此“用波去形成更低频层”的方向是正确的。

但当前 `background()` 要求连续找到多层 active root，再在所有层的共同支撑上做相邻曲线差分，并主要用去均值后的方差份额选择主导层。这个操作比用户的金融命题更严格、也更偏向“所有层先完整存在，再比较窗口方差”。真实 pilot 中 949 个评估机会全部落入 `INSUFFICIENT_HIERARCHY` 或 `NO_ROOT`，说明这个数学承载在实时时点没有可用覆盖。

因此 B 的零覆盖不应解释为金融命题失败。下一门先验收 C1/C2 的逐层可用性、实际周期和波级振幅/相位，再重新讨论 B2。

A 的正向点估计也只能解释为“值得继续检验同一多尺度分解下的小→大信息”，不能越过覆盖问题宣布预测有效。

## 8. 下一门的最低通过标准

在不看未来的前提下先做“多尺度图形分解忠实度门”：

- 每个层级的波都可单独画图验收；正例、未知、边界同规格。
- C1/C2 由逐层真实波构造，不能以层号冒充周期。
- 报告 T1/T0、T2/T0 的未经结果筛选分布。
- 报告 A1/A0、A2/A0、方向和相位覆盖，不先定盈利阈值。
- 明确区分“该层不存在/尚未确认/信息过期”与“该层弱”。
- 覆盖足够后，才分别恢复 A 的父转折增量验证和 B 的 whipsaw/continuation 验证。
- 任何未来收益或策略结果都不能参与选择层级定义、周期边界或强弱阈值。
