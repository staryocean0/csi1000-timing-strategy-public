# #372 冻结参考后的 dominance diagnostics 正式测量注册

192 条候选无关参考标签已在 Pass B 后冻结；本 profile **不把标签送入正式市场计算**。它只在同一 192 个 opaque panel 的五套 5m offset 上测量预注册的背景模型/单转折模型原始证据，并先冻结诊断文件哈希。

单转折 knot 在所有代数可用位置搜索；由于 knot 本身被搜索，使用预注册 `raw BIC + 2*log(M)` 作为搜索调整量，同时保留原始 BIC、第二优候选和跨相位稳定性。该量是测量定义，不是状态阈值。

本 run 禁止标签 join、状态赋值、阈值/迟滞/持续性拟合、未来后缀、收益/PnL、R4 或路由。正式 run 成功并冻结诊断哈希后，才允许在受控 Debian 证据层把这些分数与早已冻结的标签做**无阈值**描述性关联。
