# #353 本尺度主导性监测器：设计协议 v1

## 研究问题

每根K线收线以后，除了继续维护图形形态，还要回答：**当前这个图形尺度是否仍足以作为最近行情的可信主导表示？**
本协议只冻结问题、输出接口和反例范围；不冻结R²阈值、周期阈值、迟滞根数或市场验收线。

## 不能混为一谈的三个量

1. **Morphology**：当前pivot、完成波和发展中的腿是什么；
2. **Dominance**：当前尺度对观察路径的解释证据是否足够；
3. **Amplitude**：振幅/区间range等描述量。

低振幅可以有清晰尺度；高振幅可以有清晰尺度，也可以没有。振幅不能直接决定 `DOMINANT/NOT_DOMINANT`。

## OLS / 最小二乘只作为模型比较工具

不使用 `close ~ time` 的单一直线R²直接决定本尺度是否存在。候选诊断必须在同一个因果窗口比较：

- 背景：局部水平或单腿趋势；
- 当前尺度：背景 + 受约束的当前尺度分段几何；
- 简单谐波：仅作诊断对照，不取代项目低点骨架。

至少输出：相对背景的SSE比、增量R²、归一化残差、残差结构、支持长度和模型自由度。
近常数、病态拟合、支持不足必须单独标记。某个模板拟合差，只说明该模板证据不足，不自动证明更快频率主导。

## 因果在线状态

规划状态为：`DOMINANT / DEGRADING / NOT_DOMINANT / AMBIGUOUS / INSUFFICIENT_SUPPORT`。
每根bar只用当时已知数据，保存 `known_from`、支持区间和原因；未来后缀不能回改过去发布过的状态。
单根越线不允许直接来回翻转；真正的持续性/迟滞参数后续独立标定。

形态提取器在 dominance 被拒绝时仍继续观察。`NOT_DOMINANT` 只否定“采用当前尺度作为主导解释”的资格，不删除K线、不把这段从评估分母抹掉，也不自动reset原识别器。

## 必须先过的合成反例

- 低振幅但清晰的当前尺度波；
- 高振幅但清晰的当前尺度波；
- 总range相近但更快振荡；
- 持续单边未完成腿；
- 非正弦的合格图形波；
- 两尺度混合；
- 跳变/离群；
- 近常数；
- 尺度切换；
- offset和future-suffix反例。

## 真实评估（等待#352）

真实标签必须独立于候选版本，可允许多个相容切分和歧义。所有物理时间窗口保留在总分母。
最终同时报告漏转折、多转折、过拆/过并、几何误差、因果延迟、错误拒绝本尺度、漏掉非主导状态、歧义/支持不足占比和恢复延迟。

当前不处理“拒绝本尺度以后往更快还是更慢尺度路由”。那是后续多尺度比较问题；高振幅不等于下钻，低振幅不等于上钻。
