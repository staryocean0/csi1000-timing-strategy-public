# #359 真实行情参考：源码检查点

当前只完成**参考规则、确定性采样、盲化展示与独立验证**，尚未生成真实市场 panel，更没有看任何 #353 真实诊断分数。

## 固定的 primary sample

- 2015—2020 每季度从 #352 合格交易日中按预注册 SHA256 排名取 8 天；
- 共 24 个季度、192 个不同交易日；
- 每天只取一个因果锚点，11:00 或 14:30，由另一固定哈希位决定；
- 每个锚点只看向后 150/300 个合格交易分钟，不跨越未来数据；
- 60 分钟未来后缀只能在标签冻结后用于稳定性审计，不能回写原标签。

这套采样与 R1/R2/R3、四段 R3 gap、新诊断分数和收益完全无关。

## 两层盲化审阅

Pass A 只看归一化形状，不显示日期、数值振幅、候选识别器或诊断分数。Pass B 可以看五个 5m 相位和归一化 OHLC/wick 几何，但仍不能看候选输出。

Pass B 只能确认 Pass A，或者降级成 `AMBIGUOUS_MULTI_SCALE / DATA_INVALID_EDGE`；不能因为某个相位“更像候选算法”而升级。

## 已实现的保护

采样器和验证器各自独立实现同一哈希采样规则；验证器不导入采样器，也不导入 dominance diagnostic。盲化 inventory 只包含 panel id、固定上下文长度和未来审计长度，不包含日期/季度/失败分层。

SVG renderer 只接受归一化几何：Pass A 为形状线；Pass B 为五相位 close + high/low wick。源码不读文件、不联网、不调用任何识别器。

25 项合成合同测试验证了：192/季度平衡、顺序不变性、盲化、振幅归一后形状一致、未来审计不回填、Pass B 降级约束、turn 区间边界、独立采样复算、SVG 确定性、五相位完整性和协议禁止阈值/收益/失败样本泄漏。
