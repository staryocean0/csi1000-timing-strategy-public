# 已确认低点骨架 × 九格出现背景：V1 研究设计

研究线程：Layer2 Two-Wave；研究计划 #277。前置工具 PR #273；未完成的真实多尺度/单波/九格验收在 #274。本文件对应 `WAVE_SKELETON_CONTEXT_V1_PROTOCOL_20260916.json`。

## 1. 为什么从这里继续

研究的起点不是寻找一种买卖策略，而是把K线上的“一个波”变成可计算、可确认、可画图的对象。最初只研究两波的上涨/横盘/下跌共识，后来发现这是对丰富结构的一种有损压缩。PR #273 因而把单波独立出来，保留前后两波的九种方向组合，以及各自斜率、归一化位移和变化信息。

用户现在提出下一层问题：在同一级别下，为什么会出现上移→趋平、趋平→下移、上移→下移等不同组合？是否与更粗尺度行情的阶段有关？既然单波已被抽出，可以直接连接这些波的低点，把内部上冲回落从视图中去掉，观察留下来的慢结构。

本研究采纳这条图形路线。**不替换成拉普拉斯、傅里叶、均线或其他传统滤波器。** 上涨/横盘/下跌分类本身并不必然偷看未来；真正要防的是把事后才完整的波或连线，按发生时刻回填为当时已知。

## 2. 用户假设与待检验的解释必须分开

H1：九格的出现分布，可能随此前已经可观察的粗尺度图形背景而变化。

H0：控制可用样本、相邻波重叠、确认选择、尺度与时间分层后，没有稳健差异，或差异不足以验收。

“没有大级别趋势时，本级别周期都差不多”是有启发性的理想化假设，但不是必须成立的数学事实。振幅变化、随机扰动、波动环境、抽取窗口和截断也可能使同级波不同。因此，本研究不预设“大级别是唯一根因”。观察到条件分布不同，也只能先支持结构关联，不能从同一价格序列的分解自动证明因果驱动。

### 一个必须留下的反例

设各轮振荡中心始终是100，上下振幅依次是1、2、3、4。高点可为101、102、103、104，低点为99、98、97、96。中心没有下降，低点连线却持续下移。

因此低点骨架会混合“中心位置变化”和“下侧振幅变化”。它是本研究的候选粗尺度投影，不先叫作真实、无偏的低频趋势。后续必须保留上沿/振幅对照，不能只挑低点连线符合趋势叙事的例子。

## 3. 第一层图形过滤：从完整单波到低点骨架

对每个已经完整确认的 A-wave `L_i-H_i-L_(i+1)`，保留底线 `L_i→L_(i+1)`。所有确认单波都进入骨架，包括内部方向为RANGE、旧两波状态为Uncertain、或两波同尺度资格未通过的情况。

不能先按方向、目标周期或同尺度条件筛掉一批波，再把剩余低点跨过去连成一条“连续大趋势”。跨源epoch/reset或不共享锚点时断开；不跨断点构造父波。

已有拐点发生位置来自close选择，低点价格使用该根K线的low。我们保留这个已知口径，不偷偷改成邻域最低影线。

每条线段有两套时钟：

| 字段 | 含义 |
|---|---|
| start_bar / end_bar | 底线两端在原K线上的发生位置，用于几何 |
| known_from_bar | 完整单波确认时刻；本研究从这一收盘时刻起才允许看见该线段 |
| earliest_consumer_bar | known_from_bar+1；不假装确认bar开盘前已经知道 |

每个连续骨架的第一个起始低点，保守地随首个完整波一起进入本工具，而不是编造更早可用记录。之后共享低点去重，一条完整波新增一个终点。

可以在确认时画出端点之间的历史直线，但**不能把直线内插值视为其历史每根bar上的实时信号**；不外推未确认的右端，也不把稀疏节点重采样成假行情。

## 4. 第二层仍用图形：低点折线上的粗尺度波

对按确认顺序到达的低点节点，再使用因果的候选极值/反向成熟规则。当反向候选极值与原候选在节点序列中相隔至少 m 个位置时，确认原候选；低—高—低的已确认节点构成一个粗尺度A-wave。

这里的粗尺度“高点”是**低点骨架自身的局部高点**，不是原K线的high。它表明一段时间内市场低点整体抬升后再回落。

初始工程规格为 m=2、未完成结构上限24个节点；m=1/上限12、m=4/上限48只作为已列明的敏感性对照，不按结果挑赢家。这些不是天然频率档位；#274 的频率聚集仍未获证实。

节点是**不等时间间隔**的：成熟判定用节点数量，但几何斜率、完整周期、粗细尺度比和陈旧程度都使用原K线bar坐标。输出同时保留node span，绝不把“两个节点”偷换成“两个固定时间单位”。

粗尺度同样保留两波九格，初始描述阈值tau=.20、两波尺度比rho=sqrt(2)。这里是新候选研究，不能把旧参数已验证的说法自动扩展到父波。

| 粗尺度前后波 | 研究用背景描述 |
|---|---|
| UP→UP | 上移延续结构 |
| UP→RANGE | 上移后趋平／高位整理候选 |
| UP→DOWN | 上移转下移／向下转折候选 |
| RANGE→UP | 整理转上移 |
| RANGE→RANGE | 粗尺度区间整理 |
| RANGE→DOWN | 整理转下移 |
| DOWN→UP | 下移转上移／向上转折候选 |
| DOWN→RANGE | 下移后趋平／低位整理候选 |
| DOWN→DOWN | 下移延续结构 |

这些描述针对**最近完成并已确认的粗尺度结构**，不是上帝视角的当前市场阶段。“高位”只相对于已观察结构，不代表全局最高或真正顶部；“转折候选”不保证之后还会继续反转。

还没有完整父波、单边骨架尚未完成往返时，保留未决状态，不强造父波。原父波pair之后又确认了新的父拐点，就停止将旧pair当作有效阶段背景。父级reset清空旧背景，旧背景不得复活。

为避免无限持有旧背景，初始合格口径另要求：查询时刻距离父pair确认不超过后一父波的一个周期。同时要求父pair的较短波长至少是被研究两波较长波长的2倍。阈值是明确的初始研究规格，不是事后调参，也不改旧G carrier规则。

**后一个尺度比要等小波完成才能计算。** 所以它是事后样本资格，不是声称形成之前就知道小波的最终长度；不能为了达到比值临时挑更老、更方便的父波。

## 5. 同一案例保留三份信息截面

最危险的错误不只是偷看未来，还包括“自己解释自己”：先用这两个小波定义大背景，再发现九格与大背景吻合。这种同期吻合很可能只是同一几何被计算两次。

设被研究pair为 `L0-H0-L1-H1-L2`，第一波起点发生bar为 s，第二波确认bar为 c。

### 主要口径：形成前背景

查询截止 `s-1` 收盘，只能使用在此之前已经确认、且所有确认信息也已到达的父结构。它排除被研究两波本身，包括L0那根bar。

该口径问的是：**后来形成这些九格事件的区段，在形成前具有什么已知背景？** 起点s是事后在已确认事件中定位的，不能宣称当时已经知道这里即将形成一个pair。这仍是对随后确认事件的条件描述，不是预报事件起点。

### 诊断口径A：确认前一根

查询 `c-1` 收盘。没有读确认bar的未来信息，但可能已经包含被研究两波的部分价格和第一波确认结果，故属于有重叠的同期诊断。

### 诊断口径B：确认当时

查询 c 收盘。此时pair自身的信息也可以进入低点骨架。这一视角适合画归因图、观察粗细结构同步变化，但不能拿它证明独立的大级别驱动。

三个口径分别保存，不互相覆盖。join按同源、同视图、同配置和同连续骨架内的 `known_from_bar <= cutoff` 做backward匹配；不按发生时间、nearest或forward匹配。

实现依据仅限时钟机制：pandas官方 `merge_asof` 文档区分backward与nearest/forward；TradingView官方Zigzag说明也区分已确认和临时投影。它们不是本项目图形定义的来源，本研究不采用其Zigzag参数或算法。

参考：
- https://pandas.pydata.org/docs/reference/api/pandas.merge_asof.html
- https://www.tradingview.com/support/solutions/43000591664-zigzag-indicator/

## 6. 应该产出什么表，才能回答用户的问题

主要结果不是先宣布“某格一定是顶部”，而是产出九格×九种粗尺度背景的实际计数矩阵，并同时保留未知/陈旧/不合尺度等背景失效数量。

对每个有样本的单元，分别给出：

- `P(小波九格 | 已知粗尺度背景)`：在这类背景下，哪种小结构更常见？
- `P(粗尺度背景 | 小波九格)`：看到这类小结构时，它通常处在哪类已知背景？
- 已知背景事件群体中的基准比例和相对提升；以及所有合格小事件的边际数量，用于检查未知背景造成的选择偏差。

两个条件概率方向不同，不能混着解释。零样本分母输出null而不是0概率。全部严格pair与合格小pair分层统计；各年份也分开报告。合格已知背景数量+失效背景数量必须等于该组全部小事件数量。

这些是**按事件计数**，不等于某背景持续多少bar，也不自动等于每单位时间发生率。相邻pair共享一个波，父背景又可能被多次重复使用，不能把每行视作独立样本。

S0实现只产生描述性表，不给p值或伪造置信区间。正式推断前还需冻结按源epoch/父结构episode等单位处理依赖的对照与重抽样程序，验证其假设。若只有确认当时的重叠视角显著、形成前视角不支持，应首先记录为同期几何或证据不足，不能写成大趋势因果解释。
